## C. Why the Update Was Necessary

Mini Hivo's graduation-project thesis is that disciplined multi-role Swarm and Recursive controller engineering can amplify a single pinned weak local model (`gemma4:e4b`) into delivering verified, runnable software without cross-model cloud fallback. Before this update:

1. **Architectural opacity:** The 17 model-backed role bindings and 7-stage controller contracts were dispersed across `mini.py` and `hivo/*.py` without a unified North-Star charter or architecture reference.
2. **Protocol friction masquerading as incapacity:** When a 4B quantized model missed a tool-schema argument, hit a stale line anchor, or wrote an unclosed `<script type="importmap">`, the controller risked escalating into unproductive recursive splitting or exhausting the step budget without mutating code.
3. **Weak browser/3D quality gates and real-runtime blind spots:** A `0x0` `<canvas>` or 2D stub could satisfy `canvasCount >= 1`, while genuine Three.js r160 ES-module candidates failed due to CDN load timing, `Object3D` serialization cycles, `"Three.js"` lexical path false positives, and receipt truncation.
4. **Backend integration gaps:** External orchestrators lacked an early capability check against non-generative Ollama models and had no standardized, path-redacted JSON deliverable manifest.

## F. How the Fix Works

1. **Startup & Single-Model Capability Gate (`mini.py::main`, `select_local_ollama_model`, `hivo/model_policy.py`):**
   `normalize_requested_model_name` sanitizes `--model`, pins one model across all 17 role slots, queries Ollama `/api/show`, and runs `validate_generative_model_capabilities`. Encoder/embedding models (`['decision']` without `'completion'`/`'chat'`) terminate immediately with exit code `2` (`[SETUP_ERROR]`).

   If a leaf attempt fails, `classify_failure_episode` and `license_granularity_decision` inspect the controller-recorded tool receipts:

6. **Falsifier Supersession & Privacy-Safe Deliverable Report (`hivo/evidence.py`, `hivo/deliverable_report.py`):**
   After `Falsifier` review and `PreMutationImpactContract` post-state comparison pass, the transaction commits and `--json-report` writes relative POSIX deliverable paths, byte counts, SHA-256 digests, and run telemetry with personal host paths redacted.
